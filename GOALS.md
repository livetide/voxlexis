# Voxlexa — Language Pronunciation Trainer

**Purpose:** ASR and language trainer platform for pronunciation

## Current State

Submodule under Linguist. Code exists but goals not defined.

---

## What Voxlexa Should Do

1. **Practice** - Pronunciation practice with feedback
2. **Track** - Track pronunciation improvement over time
3. **Correct** - Identify problem areas
4. **Score** - Measure pronunciation accuracy

---

## Problems to Solve

| Problem | Current | Target |
|---------|---------|--------|
| Pronunciation not improving | Practice but no feedback | Clear improvement signals |
| Don't know what's wrong | Can't identify issues | Specific problem areas |
| No measurement | Subjective feel | Objective scores |

---

## The Evolution Loop

1. **Measure** - Get pronunciation data
2. **Identify** - What sounds are problematic?
3. **Build** - Create practice exercises
4. **Observe** - Is pronunciation improving?
5. **Iterate** - Adjust practice

**Goal:** Move from vague practice → targeted → autonomous
